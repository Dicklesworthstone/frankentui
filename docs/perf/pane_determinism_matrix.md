# Pane Execution Determinism Matrix (bd-1pvzq.4)

> Status: **implemented · deterministic · CI-enforced**
>
> Suite: `crates/ftui-layout/tests/pane_determinism_matrix.rs`
> Runs under `cargo test --workspace --all-features` (CI `check` job) and
> `cargo clippy --workspace --all-targets -- -D warnings`.

The pane lane ships four genuinely different ways to execute an operation
history. They must be **observationally identical** — same state hash after the
same history, same undo/redo trace, same rejections — regardless of which the
execution policy selects. This suite is the consolidated proof, and crucially it
emits a **structured divergence diagnostic** so a CI failure points straight at
the first bad step.

## The four substrates

| Substrate | Path | Code |
|-----------|------|------|
| **Adaptive baseline** | certified `SetSplitRatio` fast path + local-closure validation | `PaneTree::apply_operation` |
| **Conservative oracle** | always clone + whole-tree validate | `PaneTree::apply_operation_conservative` |
| **Checkpointed replay** | record + rebuild from nearest checkpoint | `PaneInteractionTimeline` `apply_and_record` / `replay` / `undo` / `redo` |
| **Persistent versions** | path-copying, `O(1)` undo/redo over shared `Arc` versions | `PaneVersionStore` / `VersionedPaneTree` |

The adaptive baseline is the reference; every other substrate is diffed against
its per-step `state_hash` trace.

## The structured divergence diagnostic (AC3)

Where the sibling `pane_operation_family_equivalence` and
`pane_persistent_equivalence` suites assert pairwise parity with bare
`assert_eq!`, this matrix routes every comparison through one pure function:

```rust
first_divergence(seed, phase, strategy, &canonical_hashes, &strategy_hashes, &cursors, op_for_index)
    -> Option<DivergenceReport>
```

`DivergenceReport` names the **first** mismatch: `seed`, `phase`
(apply/undo/redo/selector), the diverging `strategy`, the `op_index`, the
`cursor` (applied length), the offending `operation` debug string, its `family`
(Local/Structural), and both the `canonical_hash` and `strategy_hash`. On
failure the harness prints it as a single greppable JSON line
(`{"event":"pane_determinism_divergence",…}`) **before** panicking, so CI output
carries machine-readable triage context, not just a backtrace.

`first_divergence` is pure and **unit-tested directly**
(`divergence_detector_reports_first_mismatch`) with synthetic traces — including
a value mismatch, a length mismatch, and JSON escaping — so the diagnostic
machinery itself cannot silently no-op. (A determinism harness that never detects
anything would otherwise "pass" forever.)

## What the matrix covers

| Test | Axis | AC |
|------|------|----|
| `matrix_apply_equivalence_across_strategies_and_families` | 64 mixed histories × {conservative, persistent} vs baseline, all 6 families | 2 |
| `matrix_resize_dominated_histories_keep_fast_path_parity` | 48 resize-storm (≥90% Local) histories stress the certified fast path | 2 |
| `matrix_navigation_equivalence_undo_redo_across_strategies` | checkpointed replay + full undo→redo walk vs persistent `O(1)` nav, diffed against the canonical cursor trace | 2 |
| `matrix_selector_routed_execution_never_diverges` | adaptive + conservative + forced policies; the *selected* strategy's trace must equal baseline; selection is deterministic | 1, 2 |
| `matrix_retention_preserves_head_state_across_strategies` | prune store + timeline under a tight budget; head state hash must survive on both | 1 |
| `matrix_rebuild_fallback_heavy_histories_keep_parity` | MoveSubtree/NormalizeRatios (persistent rebuild-fallback path) | 2 |
| `matrix_illegal_operations_reject_identically` | reject parity + no mutation across all substrates | 2 |
| `unit_operation_family_classifier_is_correct` | classifier partitions Local vs Structural | 1 |
| `unit_selector_is_deterministic_with_fallback_triggers` | no-history→Baseline, forced override, conservative→Checkpointed, resize-storm→Persistent; determinism | 1 |
| `unit_checkpoint_spacing_responds_to_cost_ratio` | cheaper snapshots checkpoint at least as often; deterministic | 1 |
| `divergence_detector_reports_first_mismatch` | the diagnostic itself | 3 |

## Determinism & cost (AC4)

Every history is generated by a seeded SplitMix64 (`Lcg`) shared with the sibling
suites, so the matrix is bit-reproducible. Seed counts and history lengths are
bounded (≤64 seeds × ≤64 steps) to stay cheap under `cargo test`, while the
resize-storm and rebuild-fallback sections guarantee both the Local fast path
and the structural rebuild paths are exercised every run.

## Relationship to the perf gates

This is the *semantic* half of the bd-1pvzq verification lane; the *artifact*
half is the symbolized replay bundle (`docs/perf/pane_replay_artifacts.md`,
bd-1pvzq.1). Together they let bd-1pvzq.3 (golden replay-oracle + differential
certification) and bd-1pvzq.5 (E2E soak/rollback) assert both "the strategies
agree" and "here is the exact replayable, symbolizable evidence."
